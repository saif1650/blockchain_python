# Blockchain Python ⛓️

This project is part of my personal learning journey in blockchain development using Python.  
It demonstrates the creation of a simple blockchain with proof-of-work, validation, and mining features.

### 🧠 Features
- Block creation and validation  
- Proof-of-Work (PoW) mining mechanism  
- Chain verification for integrity  
- Reward system for miners  

### 🛠️ Tech Stack
- **Language:** Python  
- **Environment:** VS Code  
- **Version Control:** Git + GitHub  

### 🚀 My Goal
To learn blockchain technology through practical implementation and grow towards building decentralized applications (DApps).
